# Политика конфиденциальности приложения «Betula (ЭкоБерёза ФА)»

Дата вступления в силу: 16 ноября 2026 г.

## 1. Общие положения
Мобильное приложение **Betula** (`ru.ecobirch.fa.app`) предназначено для экологического мониторинга и расчёта флуктуирующей асимметрии листьев берёзы повислой (*Betula pendula*). Приложение спроектировано по принципу **offline-first**: сбор, хранение и математический анализ данных выполняются локально на устройстве пользователя.

## 2. Какие данные обрабатываются
1. **Фотографии листьев и EXIF-метаданные**: изображения, снятые камерой или выбранные из галереи, сохраняются во внутренней защищённой памяти приложения (`filesDir/leaf_photos/`).
2. **Географические координаты**: координаты GPS/сети (при разрешении пользователя) используются исключительно для привязки точек сбора листьев на карте и расчёта территориальной статистики.
3. **Журнал наблюдений**: названия территорий, морфометрические координаты 12 точек и расчётные показатели ($Y_1 \dots Y_5$, $Z$, $FA$) хранятся в локальной базе данных SQLite (Room).

## 3. Передача данных третьим лицам
- По умолчанию приложение **не передаёт** фотографии и журнал наблюдений на сторонние серверы. Локальное выделение контура листа работает полностью на устройстве.
- **Карты и геокодинг**: при просмотре карты и поиске адресов приложение обращается к публичным сервисам OpenStreetMap / Nominatim / Photon (передаётся только строка поискового запроса или координаты выбранной точки для получения названия улицы/парка).
- **Опциональный облачный ИИ (Google Gemini API)**: отправка фотографии листа в Google Gemini API происходит **исключительно** по явному решению пользователя после принятия политики конфиденциальности и ввода собственного API-ключа в разделе «Настройки».

## 4. Управление данными и удаление
Пользователь полностью контролирует свои данные:
- Может экспортировать журнал в JSON (демо-данные по умолчанию исключаются из экспорта).
- Может удалить отдельные листья, территории или полностью очистить локальную базу данных с двойным подтверждением.
- Удаление приложения полностью удаляет все локальные данные и фотографии из песочницы приложения.
